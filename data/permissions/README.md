# Written permissions

Brief section 2: data under CC BY-NC, custom terms or anything else outside CC0 and CC BY is used only with the data owner's written permission, stored here.

- One file per permission: `YYYY-MM-DD_<movebank-study-id>_<owner>.md` (or `.pdf`/`.eml` for the original).
- Record: who granted it, for which study and use, any conditions (credit wording, scope, expiry), and the exact text of the grant.
- Remove personal data not needed as proof (phone numbers, signatures) before committing.
- The study's entry in `../studies.json` references the file in `permissionRef`.
